# Reproducibility Guide

This document defines the exact steps and assumptions used to reproduce the full pipeline outputs in this repository.

## Scope

The reproducible run covers:

1. Dataset build
2. Model training and evaluation
3. Adversarial simulation
4. Simulation analysis
5. Figure generation

## Environment

Minimum:

- Python 3.8+
- `pip install -r requirements.txt`

Recommended for thesis reproducibility records:

1. Record the Python executable path (`python -c "import sys; print(sys.executable)"`)
2. Record the Python version (`python --version`)
3. Keep a copy of `requirements.txt` used at submission time

## Determinism and Seeds

The project currently uses seed `42` in core data/model pipeline functions:

- `src/build_dataset.py` for shuffling and balancing
- `src/mvp_baseline.py` for train/test split and SHAP row sampling

The reproducibility runner also exports:

- `PYTHONHASHSEED=42`
- `FYP_RANDOM_SEED=42`

Use seed `42` when you need output-identical reruns for dissertation evidence.

## One-Command Reproduction

From the project root:

```powershell
.\run_reproducible_pipeline.cmd
```

or:

```bash
python src/reproduce_pipeline.py --seed 42
```

Optional (skip dataset rebuild):

```bash
python src/reproduce_pipeline.py --seed 42 --skip-build-dataset
```

## Outputs Produced

Primary outputs generated by a full rerun:

- `models/tfidf_vectorizer.joblib`
- `models/logreg_model.joblib`
- `models/multinomial_nb_model.joblib`
- `simulation_results/attacker_simulation_log.csv`
- `simulation_results/analysis/*.csv`
- `simulation_results/figures/*.png`
- `simulation_results/reproducibility_run_metadata.json`

## Metadata File

Each reproducible run writes a metadata file with:

- UTC start/end timestamps
- Python version and executable path
- OS/platform details
- Seed and reproducibility environment variables
- Duration per pipeline stage

This metadata should be kept with dissertation appendices when reporting final experimental runs.
